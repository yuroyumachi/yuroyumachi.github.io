yud 1.0 -- a portable development environment for Windows x86_64 with busybox, GNU make, Lua and TinyCC in one folder. Unzip it, run yud.bat, done.

Everything in it was compiled by TinyCC, including TinyCC itself:

lua5.1.4 (lua/dll/ for loading C modules)
tcc0.9.27 (x86_64 Windows)
